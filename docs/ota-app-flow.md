# ECM — تدفّق التحديث من التطبيق

البورده أوفلاين على شبكة داخلية. التطبيق هو الوسيط: بينزّل الفيرموير من الموقع، يخزّنه عنده، وبعدين يرفعه على البورده محليًا.

```
 ①②③ إنترنت                    ④⑤ شبكة داخلية (بدون إنترنت)
┌──────────────┐   token    ┌──────────┐   X-ECM-Key   ┌──────────┐
│  ووردبريس    │ ←────────→ │ التطبيق  │ ←───────────→ │ البورده  │
│  .bin محمي   │            │  كاش     │               │ Update.h │
└──────────────┘            └──────────┘               └──────────┘
                                 ⑥ يرجع يبلّغ لما الإنترنت يرجع
```

---

## المراحل

### ① تسجيل الدخول (مرة واحدة)

```http
POST /wp-json/ecm/v1/app/login
username=...&password=...&device_id=...&device_name=...
```

→ `{ "ok": true, "token": "...", "devices": ["ECM-0001", ...] }`

خزّن `token` — هو مفتاح كل نداءات الـ OTA. ابعته في هيدر `X-ECM-App-Token` أو كبراميتر `token`.

### ② تنزيل الكتالوج (وانت على الإنترنت)

```http
GET /wp-json/ecm/v1/ota/app/catalog?model=default
X-ECM-App-Token: <token>
```

```json
{
  "ok": true,
  "model": "default",
  "channels": {
    "stable": [
      { "version": "1.2.0", "url": "https://.../ota/download?r=7&s=u%3A12&e=...&k=...",
        "md5": "9f86...", "sha256": "...", "size": 892144,
        "mandatory": false, "notes": "إصلاح انقطاع الواي فاي", "released": "2026-09-01 12:00:00" },
      { "version": "1.1.0", "...": "..." }
    ],
    "beta": [ ... ]
  },
  "link_ttl": 86400,
  "check_in": 21600
}
```

الكتالوج بيرجّع آخر كام إصدار لكل قناة (مضبوطة من اللوحة). **نزّلهم كلهم وخزّنهم** — ده اللي بيخلّي التطبيق يقدر يشتغل بعد كده من غير إنترنت، ويقدر يرجّع نسخة أقدم لو الجديدة عملت مشكلة في الموقع.

### ③ تنزيل الـ .bin

```http
GET <url من الكتالوج>
Range: bytes=524288-        ← اختياري، للاستكمال بعد انقطاع
```

- الرابط موقّع ومربوط بحسابك وبينتهي بعد `link_ttl` (افتراضي 24 ساعة).
- **تحقق من الـ MD5 بعد التنزيل** وقارنه باللي جه في الكتالوج. لو مش مطابق، امسح الملف وأعد التنزيل — **متبعتش ملف مشكوك فيه للبورده**.
- خزّن مع الملف: `version`, `md5`, `model`, `notes` — هتحتاجهم وانت أوفلاين.

### ④ لقاء البورده على الشبكة الداخلية

اتصل بشبكة البورده، وبعدين:

```http
GET http://ecm-ECM-0001.local/ecm/info     (أو http://<ip>/ecm/info)
X-ECM-Key: <المفتاح المحلي بتاع البورده>
```

→ `{ "serial": "ECM-0001", "model": "default", "version": "1.0.0", "free": 1310720, ... }`

قارن `free` بحجم الملف قبل ما تبعت. لو الملف أكبر، الفلَش هيفشل.

لو عندك إنترنت في اللحظة دي، اسأل السيرفر رأيه:

```http
GET /wp-json/ecm/v1/ota/app/check?serial=ECM-0001&version=1.0.0&model=default
X-ECM-App-Token: <token>
```

→ بيرجّع `update: true/false` + بيانات الإصدار المناسب للبورده دي بالذات (بيراعي نسبة الطرح والقناة والإصدار المثبّت من اللوحة).
لو مفيش إنترنت، قارن بنفسك بين `version` بتاعت البورده وأحدث نسخة في الكاش.

### ⑤ الرفع على البورده

```http
POST http://<ip>/ecm/update
X-ECM-Key: <المفتاح المحلي>
X-ECM-MD5: <md5 بتاع الملف>
Content-Type: multipart/form-data

firmware=<الملف>
```

→ `{ "ok": true }` والبورده بتعمل restart، أو `{ "ok": false, "error": "..." }`.

استنى 5–10 ثواني وبعدين اسأل `/ecm/info` تاني عشان تتأكد إن `version` اتغيّرت فعلاً. **ده هو التأكيد الحقيقي** — رد `ok:true` لوحده مش كفاية.

### ⑥ البلاغ (أول ما الإنترنت يرجع)

```http
POST /wp-json/ecm/v1/ota/app/report
X-ECM-App-Token: <token>

serial=ECM-0001&version=1.2.0&status=success&model=default&local_ip=192.168.4.12
```

`status` = `success` / `failed` / `updating`. لو `failed` ابعت `error` كمان (نص قصير).

**اعمل طابور للبلاغات.** التطبيق ممكن يفضل ساعات من غير إنترنت بعد ما يحدّث كذا بورده — خزّنهم محليًا وابعتهم كلهم لما الشبكة ترجع. البلاغات دي هي المصدر الوحيد لبيانات لوحة الأسطول.

## أخطاء متوقعة

| الرد | المعنى | التصرف |
|---|---|---|
| `401 invalid_token` | التوكن باظ أو الحساب اتربط بجهاز تاني | رجّع المستخدم لشاشة الدخول |
| `403 serial_not_yours` | السيريال مربوط بحساب تاني | اعرض رسالة واضحة — مش مشكلة شبكة |
| `403 invalid_or_expired_link` | رابط التنزيل خلصت صلاحيته | اطلب الكتالوج تاني واستخدم الرابط الجديد |
| `429 too_many_requests` | خنق | استنى واعمل backoff تصاعدي |
| `503 ota_disabled` | النظام متوقف من اللوحة | اعرض "التحديثات موقوفة مؤقتًا" |

## نقط مهمة في تنفيذ التطبيق

1. **التحقق من MD5 مرتين** — مرة في التطبيق بعد التنزيل، ومرة على البورده عن طريق هيدر `X-ECM-MD5`. البورده مش هتعتمد الصورة لو البصمة مش مطابقة.
2. **متمسحش النسخة القديمة من الكاش** بعد التحديث — دي طريقتك الوحيدة للرجوع لو الجديدة فيها مشكلة والمستخدم مش على إنترنت.
3. **الموديل مهم** — بورده موديل `cam` مالهاش لازمة بفيرموير موديل `relay`. اقرا `model` من `/ecm/info` واستخدمه في كل نداء.
4. **لو التحديث إجباري** (`mandatory: true`) اعرضه بوضوح ومتخليش المستخدم يعدّيه.
5. **البطارية والاتصال** — متبدأش رفع على البورده والتطبيق على بطارية ضعيفة أو إشارة ضعيفة. انقطاع في النص بيسيب البورده على صورة ناقصة (هي بترجع للقديمة، بس التجربة وحشة).
